# obsidian-daily-note-jump

An Obsidian plugin that jumps to the daily note for a specified date or the current day via a command palette action.

## Stack

Primary language: **TypeScript**

## Project structure

- `main.ts` — Provides a command to navigate directly to the daily note for today or a user-specified date.
- `package.json` — dependencies
- `tests/test_main.ts` — basic tests

## Usage

Review the source files and install any dependencies referenced by the project before running it.
